# Jadual Rawatan - Pusat Kesihatan Drehab AF

Next.js full version webapp.

## Run locally

```bash
npm install
npm run dev
```

## Deploy to Vercel

Upload/push repo to GitHub, then import project in Vercel.

## Features

- iPhone-style webapp UI
- Temujanji Pesakit form
- Nama Pesakit & Juruterapi auto uppercase
- Slot validation: same therapist cannot overlap at same date/time
- LocalStorage persistence
- Weekly schedule Isnin-Ahad
- WhatsApp current-week schedule export to 0189562511
- Compact appointment drawer
- Dock links: daftar.drehabaf.com, rekod.drehabaf.com, app.drehabaf.com
